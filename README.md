## 🛠️ Step-by-Step Troubleshooting

1. Check the latest Steam update and restart Steam to ensure the installed build is current.
2. Use Steam > Installed Files > Verify integrity of game files to check installation data.
3. Temporarily disable overlays and unrelated injectors, then attempt a fresh launch.
4. Update or test a known stable graphics driver and ensure Windows is fully updated.
5. Inspect Windows Reliability Monitor or Event Viewer for an application fault timestamp matching the launch.
6. If repeatable, record the game version, graphics adapter, error text, and exact moment of the crash for support.
